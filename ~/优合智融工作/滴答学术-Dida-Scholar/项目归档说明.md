## 🚀 快速启动

### 本地运行

```bash
# 1. 进入项目目录
cd ~/优合智融工作/滴答学术-Dida-Scholar

# 2. 安装依赖
cd backend
npm install

# 3. 启动后端
node production-server.js

# 4. 启动前端（新终端）
cd demo-web
python3 -m http.server 8080

# 5. 访问
# http://localhost:8080/index-fixed.html
```

### 生成新文章

```bash
cd backend/crawler
node collect-with-real-ai.js
```

### 导出静态数据

```bash
cd backend
node export-static.js
```
