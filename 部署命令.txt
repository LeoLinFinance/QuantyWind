📝 接下来的步骤：

1️⃣ 在GitHub创建仓库
   访问: https://github.com/new
   仓库名: didaxueshu
   类型: Public
   不要勾选 "Initialize with README"

2️⃣ 推送代码（在终端运行）

# 添加远程仓库（替换为你的仓库URL）
git remote add origin https://github.com/你的用户名/didaxueshu.git

# 推送代码
git branch -M main
git push -u origin main

3️⃣ 启用GitHub Pages
   仓库页面 → Settings → Pages
   Source: Deploy from a branch
   Branch: main
   Folder: /demo-web
   点击 Save

4️⃣ 访问网站
   https://你的用户名.github.io/didaxueshu/index-static.html

💡 如果推送时需要认证：

方式1: Personal Access Token
   1. 访问 https://github.com/settings/tokens
   2. Generate new token (classic)
   3. 勾选 repo 权限
   4. 复制token
   5. 推送时用token作为密码

方式2: SSH密钥
   ssh-keygen -t ed25519 -C "professionalleolin@gmail.com"
   cat ~/.ssh/id_ed25519.pub
   # 复制公钥到 https://github.com/settings/keys
